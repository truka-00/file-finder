# 파일 찾기

윈도우 컴퓨터의 바탕화면·다운로드(원하면 메신저 받은 파일 폴더까지) 파일을 **이름과 내용으로** 바로 찾는 검색기입니다.
학교에서 쓰는 한글(hwp·hwpx)·PDF·엑셀·워드 속 글자까지 찾고, 스캔한 PDF는 윈도우 글자 인식으로 읽습니다.

- 바탕화면 **`파일 찾기`** 아이콘 또는 **`Ctrl + Alt + F`** → 주소창 없는 검색 창이 뜹니다
- 띄어쓰기로 여러 낱말을 넣으면 모두 들어 있는 파일만, ↑↓ 로 고르고 Enter 로 열기
- (선택) **다운로드 자동 정리**: 하루 한 번(오후 5시 30분) 다운로드 폴더 파일을 이름 낱말로 바탕화면 번호 폴더에 옮깁니다. 애매한 파일은 `0. 분류 대기`, 똑같은 파일이 이미 있으면 `9. 정리 대기/중복 파일` 로. 지우는 건 하나도 없습니다.

## 개인정보
- 모든 것이 **내 컴퓨터 안에서만** 돌아갑니다. 인터넷 서버에 올리지 않고, 이 컴퓨터(127.0.0.1) 밖에서는 접속되지 않습니다.
- 색인(파일 속 글자 모음)은 `%LOCALAPPDATA%\파일찾기\index.db` 에만 저장됩니다. 학생 이름이 들어 있을 수 있으니 이 파일과 `config.json` 은 공유하지 마세요 (저장소에는 들어가지 않게 막혀 있습니다).

### Claude 가 할 일 (직접 설치할 때도 같음)
1. 파이썬 3.10 이상 확인. 없으면 `winget install Python.Python.3.12`
2. `git clone https://github.com/truka-00/file-finder ~/개발/파일찾기`
3. `config.example.json` 을 `config.json` 으로 복사하고 사용자에게 맞게 고치기 (아래 설명)
4. `powershell -ExecutionPolicy Bypass -File setup.ps1` (자동 정리를 빼려면 `-NoSort`)
5. 바탕화면 `파일 찾기` 아이콘을 눌러 검색 창이 뜨는지 확인

## config.json 고치는 법

| 항목 | 뜻 |
|---|---|
| `검색할 폴더` | `"보일 이름": "경로"`. 예: 메신저 받은 파일 폴더를 추가 `"쿨메신저": "~/Documents/CoolMessenger"` |
| `검색에서 뺄 폴더` | 이 이름의 폴더는 건너뜀 (프로그램 개발 폴더 등) |
| `글자 인식 최대 쪽수` | 스캔 PDF 를 몇 쪽까지 읽을지. 0 이면 글자 인식 안 함 |
| `단축키` | 검색 창을 여는 키. 예: `Ctrl+Alt+F` |
| `다운로드 정리 › 규칙` | 위에서부터 차례로, 파일 이름에 `낱말` 중 하나라도 있으면 `폴더` 로 옮김. 폴더는 `옮길 곳`(기본: 바탕화면) 아래에 자동으로 만들어짐 |

고친 뒤에는 `setup.ps1` 을 다시 실행하면 적용됩니다.

## 쓰다가

| 하고 싶은 것 | 명령 (이 폴더에서) |
|---|---|
| 정리가 어디로 갈지 미리 보기 | `python sorter.py --dry` |
| 지금 바로 정리 | `python sorter.py` |
| 마지막 정리 되돌리기 | `python sorter.py undo` |
| 터미널에서 검색 | `python indexer.py search 낱말` |
| 자동 정리 끄기 | `setup.ps1 -NoSort` |
